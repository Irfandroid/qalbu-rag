# Dataset Quran Qalbu

Inventaris ini adalah daftar referensi ayat pada corpus aktif `qalbu-kemenag-v1`. Rentang bersifat inklusif; setiap ayat menjadi satu parent document.

## Ringkasan

| Item | Nilai |
|---|---:|
| Parent ayat | 282 |
| Child `arabic` | 282 |
| Child `translation` | 282 |
| Child `tafsir` | 282 |
| Child `themes` | 225 |
| Subset manifest refleksi | 201 |
| Surah tercakup | 84 |

Jumlah child `themes` lebih kecil dari parent karena child hanya dibuat saat field tema sumber
memiliki isi. Endpoint katalog dataset menghitung jumlah aktual dari `quran_chunks`; angka di atas
adalah snapshot manifest corpus yang diverifikasi pada 2026-10-13.

## Parent–child

```text
quran_documents (1 row per ayat)
└── quran_chunks
    ├── arabic
    ├── translation
    ├── tafsir
    └── themes
```

Child hanya dibuat jika field sumber tidak kosong. Setiap child menyimpan `parent_id`, `verse_key`, `corpus`, provenance Kemenag, dan metadata embedding. Retrieval mencari child, lalu mengembalikan parent unik.

## Sumber dan batasan

- Provider: Quran Kemenag API.
- Otoritas: LPMQ Kementerian Agama RI.
- Terjemahan: Terjemahan Kemenag 2019.
- Tafsir: Tafsir Kemenag Ringkas dan Tahlili.
- Katalog web hanya menampilkan metadata referensi; teks lengkap tidak dipublikasikan di halaman inventaris.
- `qalbu-seed-v1` dipertahankan sebagai corpus rollback.
